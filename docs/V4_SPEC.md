## 1. 세계관과 큰 줄기

**혈월(血月)**: 해마다 뜨는 붉은 달. 천마신교의 시조 '혈월천마'가 만든 굴레의 상징. 죽으면 같은 해 봄으로 되돌아가는 회귀의 근원이다.
**진실**(후반에 서서히 드러남): 스물세 천마는 모두 이 굴레를 끝내려다 실패했고, 그 잔영이 천마총 깊은 곳에 남아 있다. 굴레의 힘을 노리는 세력이 **구천문(九天門)** — '하늘 위의 하늘(천외천)'로 오르려는 아홉 자리의 초월자들이다. 혈월의 힘을 모아 문을 열려 한다.
**청년기(1~36개월) 결과**는 `S.path`로 이어진다:
- `ma` 세계(guard, throne, cheonma, shadow): 마교 쪽. 마교가 건재하거나 당신이 마교의 중심.
- `jeong` 세계(betray, maengju, peace): 정파 무림맹 쪽.
- `wander` 세계(flee, burn): 소속 없이 떠돎. 마교는 몰락했거나 재가 되었다.
- `S.path === 'true'`: 굴레를 끊은 자(`S.noReturn`): **죽어도 회귀하지 않는다(죽음 = 영원한 끝)**. 세계는 `S.route`에 따라 ma/jeong. 이 경우 죽는 이벤트(`die()`)는 진짜 끝이니 더 신중하게, 대신 보상은 더 크게 가능.
- 텍스트는 `W(마교, 정파, 방랑)` 헬퍼로 세계마다 달리 쓴다(방랑 생략 시 마교 문장).

**기존 인물**: 독고강(외당 교관, 외팔), 홍란(약당 의원), 묵야(눈먼 장로), 연이(같은 방 시종, 당신의 소꿉벗), 위무강(교주, 병들었음; 살아 있으면 `F.masterAlive`), 사마령(그림자 호법), 백운(무당 속가 제자·첩자), 철노(대장장이), 한서생(서고지기), 남궁진(검성), 제갈휘(무림맹 책사/무공), 청허(무림맹주), 단목환(배신자 좌호법; 대개 죽음 `F.danDead`).
각 인물의 생사는 청년기 분기에 달렸다. 죽음 플래그: `S.flags.dgDead, hrDead, mkDead, ynDead, masterDead, cnDead, hsDead, njDead, bwDead, smDead, danDead`. 확실하지 않으면 `alive('dg')`로 확인하고, **이야기에서 죽이려면 해당 플래그를 반드시 세워라**(그래야 인연 목록에서 사라진다).
`S.trust.xx`: 신뢰도(0~5). `tr('xx')`. 청년기 flags: `F.siegeWon`, `F.heir`, `F.throne`, `F.purge`, `F.fleeWith`(연이와 함께 떠남) 등.

## 2. API (전역 함수/변수)

### 이벤트 등록
```js
// 장 이벤트: 정확히 그 개월에 한 번 발생. 조건 맞지 않으면 건너뜀.
EVENTS.push({ m: 130, id: 'a_gate', cond: function () { return worldOf() !== 'wander'; }, run: function () { ... } });
// 우연한 사건: 한 달 행동이 끝날 때마다 20% 확률로 풀에서 뽑힘.
LIFE.push({ id: 'a_rumor', from: 19, to: 40, world: ['ma','jeong'], w: 3, once: 'life', cd: 36, cond: fn, run: fn });
```
- `id`는 **파일 접두사**로 시작(A→`a_`, B→`b_`, C→`c4_`, D→`d_`). `story_core.js`는 `c_`를 이미 씀.
- `from`/`to`: 나이 범위. `world`: ['ma','jeong','wander']. `w`: 가중치. `once:'life'`(한 번), `once:'save'`(평생 한 번), `cd`: 재발생까지 최소 개월(없고 once도 없으면 48).
- **run()은 반드시 `done(text, kind)`로 끝나거나 `finish()`/`die()`로 끝나야 한다.** 중간 장면은 `scene`/`result`/`pages`로 잇는다. 이벤트 자체는 한 달을 소모하지 않는다(마지막 done이 달을 넘기는 게 아니라 허브로 돌아간다).
- `kind`(로그 아이콘): 'event','qi','rest','fight','fail','people','item','skill','realm'.

### 장면
```js
scene(title, bodyHtml, [ {t:'선택지', h:'힌트(결과 암시)', c:'primary'(선택), off:'비활성 사유'(조건 불충족 시), f:function(){...}} ], artKey);
result(title, bodyHtml, continueFn, artKey);          // [계속] 버튼 하나
pages(title, [ps('문단1','문단2'), ...], artKey, doneFn); // 연속 쪽
ps('문단1','문단2') // <p>로 감싼다.  esc(text)로 사용자/가변 문자열 이스케이프
```
- artKey(그림): `dawn, r0~r8, return, insight, night, siege, throne, guard, flee, betray, burn, death, true, peace, shadow, ch1~ch6, bloodpool, alliance, wudang, cheonma, maengju, arena, court, loc_hill, loc_lib, loc_forest, loc_village, loc_border, loc_tomb`. 맞는 그림이 없으면 생략(기본 그림).
- 본문은 **2인칭 '당신'**, 과거형 서술, 짧은 문단. `<b>`로 핵심 수치 강조. 선택지 `h`에는 결과를 암시하되 정확한 숫자는 보상 계산식에 맞춰 표기.

### 상태와 보상
- `S.realm`(0~8), `S.qi`, `S.hp`, `maxHp()`, `S.mad`(0~100), `S.silver`, `S.month`, `age()`, `yearOf()`, `S.flags.xx`, `S.items.pill/antidote/calm/ore`, `S.mat`(재료: herb iron hide bone jade gem scale core; `addMat(k,n)`, `mat(k)`), `S.trust`, `S.weapon`, `S.armor`, `S.acc`, `S.disc`(제자 배열 {n,p,t,a}), `S.sect`({n,lv}), `S.estate`, `S.lifeBonus`(수명+년), `S.hpBonus`.
- **돈은 `price(n)`** (시간 지나며 오르는 물가), **내공은 `qiGain(n)`**(획득 보정) 또는 **`qiPct(p)`**(지금 경지 폭의 p 비율; 큰 보상 0.03~0.12, 작은 보상 0.01~0.03). 고정 숫자 내공/은전은 후반에 무의미해지니 쓰지 말 것.
- `hurt(p)`: 최대 체력의 p 비율 피해(죽지 않음). `learn('무공id')`. `learnMem('기억id')`(회귀해도 남는 지식), `hasMem(id)`.
- `S.lifeBonus += 2`(수명 연장, 최대 12), `S.mad = clamp(S.mad+n,0,100)`, `S.hpBonus += n`.
- 다음 도구: `tr('xx')`, `gain(who, g, text, nextFn)`(NPC 방문 결과+신뢰 +g; `MS[who]`의 마일스톤 처리), `meet('xx')`(새 NPC를 알게 됨), `alive('xx')`.

### 전투
```js
fight('적id', tier, { auto:true, spar:false, title:'제목', heal:0.2, hpMul:1, win:fn, lose:fn });
efight('적id','제목', winFn, lethalFalse?, mul)   // tier=et()=realm*.7 자동
```
- `tier`는 적 강화 배율(1+tier*0.45). 보통 `et()*0.8~1.2` (보스는 `et()+0.5`). 후반 보스는 `et()+1`까지.
- `spar:true`면 져도 죽지 않고 `lose` 호출(체력 30% 정도 회복 후 처리). `spar:false`+`lose:function(){die('id');}`는 치명적 전투 — **진행에 중요한 보스에만**, 나머지는 spar로.
- 적 정의: `ENM.접두사_id = {n:'이름', hp:기준체력, atk:기준공격, def:(선택), boss:true, w:{strong:3,rapid:2,feint:3,charge:2}}; GLY.접두사_id='字';` 기준값은 tier 1.0 기준: 졸개 hp 60~110 atk 12~18, 강자 hp 120~220 atk 18~26, 보스 hp 250~420 atk 26~38. 기존 `ENM`의 elder, chaser, kjBoss, jg, gs, cm, swordsman, taoist, stone, ghost, beast 재사용 가능.
- `w`의 의미: 적이 고를 수(강타/연타/허초/운기) 가중치. 성격에 맞게 짠다(힘 센 놈은 strong·charge, 빠른 놈은 rapid, 교활한 놈은 feint).

### 새 인물 (조연은 초상화 없이 졸라맨이 자동으로 그려짐)
```js
addNpc('a_sohwa', { n:'소화', role:'떠돌이 여협', desc:'한 줄 소개', world:['ma','jeong','wander'], flag:'a_sohwa_met', dead:'a_sohwaDead' },
  function VIS() { scene('...', npcHead('a_sohwa') + '<p>...</p>', [ {t:'...', h:'...', f:function(){ gain('a_sohwa',1,'결과 텍스트'); }}, {t:'돌아간다', f:function(){ hub(); }} ]); },
  [ {t:2, run:function(d){ ... result('제목','<p>...</p>', d); }} ]   // 신뢰 2 도달 시 마일스톤 (d는 계속 콜백)
);
// 등장은 이벤트 안에서: meet('a_sohwa'); S.flags.a_sohwa_met = true;  (flag를 쓰면 flag가 켜질 때 인연 목록에 나타남)
```
- 방문(VIS)은 한 달을 소모한다(`gain`이 `advance` 호출). 방문마다 보상(체력/마기/내공/은전/정보)을 줘서 갈 이유를 만든다.
- 새 인물은 시대당 2~3명이 적당. 퇴장(죽음/이별)도 쓸 것.

### 기억(회귀 지식)과 죽음, 결말
- `MEM.접두사_id = ['제목','다음 생에 도움이 될 한 줄 설명']; learnMem('접두사_id');` — 회귀 후 이 지식으로 더 잘 대응하는 이벤트를 만들어라(`hasMem()` 분기). 이야기의 핵심 재미.
- 죽음 정의: `DEATHS.접두사_id=['제목','본문 한두 문장'];` → `die('접두사_id')`. 죽으면 보통 회귀(시대 초입으로 되감기 선택지가 나옴). `S.noReturn`이면 영원한 끝.
- 새 결말(후반 D 작가만): `ENDINGS.d_id=['이름', 점수];` + `ART.d_id=['end_true','','50% 50%'];` + `ENDTEXT4.d_id=function(){return ps(...);}` → `finish('d_id')`.

### 업적/세계 분기/기타
- 업적: `ACH.접두사_id=['이름','설명']; ach('접두사_id');`
- 세계 분기 문장: `W(마교, 정파, 방랑)`; 큰 분기 `if (worldOf()==='jeong')`.
- 시간 경과 서술에는 `age()`를 쓰되 정확한 숫자는 과하지 않게.
- 장비/상점은 건드리지 말 것(economy.js). 보상으로 재료(`addMat`)나 장비 지급은 가능: `S.weapon = Math.max(S.weapon, 5)`처럼.

## 3. 작성 원칙
- **분량**: 장 이벤트(EVENTS) 시대당 약 6~10개 + 우연한 사건(LIFE) 시대당 약 10~16개. 한 이벤트 본문 3~6문단. 선택지 2~4개, 각 선택은 결과가 다르다(스탯/플래그/기억/전투). 선택지 힌트 `h`를 꼭 쓴다.
- **다양성**: 같은 틀의 복붙 금지. 전투·대화·퍼즐·선택·미니 이야기·인물 후일담·계절 풍경·소문을 섞는다. LIFE는 반복 가능성이 있으니 문장에 가변 요소(`pick`, `W`, 현재 경지/나이)를 넣어 어색함을 줄인다.
- **연결**: 시대마다 중심 사건이 있다(§1 표). 장 이벤트들이 하나의 줄거리를 이루게 하고, LIFE는 풍경·인연·소소한 사건으로 채운다. 앞 시대 사건을 `S.flags`로 이어받아도 좋다(없을 때도 말이 되게).
- **세계 3종**: 모든 이벤트가 세 세계에서 어색하지 않게. 힘들면 `world:[..]`로 제한하고 다른 세계용 대체 이벤트를 둔다.
- **회귀**: `S.noReturn`이 아니면 죽어도 회귀한다. 플레이어가 한 번 겪은 사건을 다음 생에서 알고 대응할 수 있게 `MEM`을 설계한다(특히 장 이벤트).
- **밸런스**: 보상은 시대에 비례(`price`, `qiPct`). 평균적으로 한 이벤트가 내공 한 경지 폭의 1~8%를 넘지 않게. 목숨이 걸린 전투는 이기면 큰 보상, 질 가능성이 충분히 있게.
- **금지**: 실제 인물/브랜드, 노골적 성적·고어 묘사, 정치적 실존 주장. 무협 장르의 폭력은 수위 내에서.
- **문체**: 기존 `story.js`처럼 짧고 건조한 서술, 하드보일드한 무협체. 과한 수식 금지. 대사는 “ ” 사용.

## 4. 점검

- 이벤트 점검(필수): `node tools/evtest.js <id접두사> 40` — 세계×경지×나이를 섞어 각 이벤트를 수십 번 돌려 오류/막힘/'undefined'를 찾는다. **문제 없음**이 나올 때까지 고친다.

## 5. 마지막 혈월 (작가 D 전용)
- 수명(`lifespan()`)은 보통 86~92세다. 최종 결전은 `EVENTS.push({m:'final', id:'d_final', run:...})`로 등록한다 — 수명보다 3년 앞선 해(`finalMonth()`)에 자동으로 발생한다. 그 전에 죽지 않은 모든 플레이어가 겪는다.
- E10(91~96세) 이벤트는 수명이 긴 플레이어만 만나는 '덤'이다. 최종 결전 이후의 후일담 위주로 쓴다.
- 최종 결전의 결말은 플레이어가 쌓은 것(문파·제자·동맹·진실에 대한 앎·`S.path`)에 따라 갈린다. 결말 id는 `d_`로 시작, 5~6개: 문을 닫다(희생), 문을 부수다, 승천하다, 굴레를 이어받다, 이름 없는 평화(세계/제자에게 맡김), 진엔딩(`S.noReturn`일 때만 열리는 결말) 등.
